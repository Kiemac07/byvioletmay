# ByVioletMay Website

A responsive, multi-page static website for ByVioletMay.

## Pages
- `index.html` — Home
- `about.html` — About Violet + client reviews
- `services.html` — Services & pricing
- `book.html` — Booking page ready for a booking system integration

## Contact
- Email: violetmaye153@gmail.com
- Instagram: https://instagram.com/byvioletmay

## Design
Warm ivory, espresso brown and muted cocoa tones, using Cormorant Garamond for the editorial serif typography and DM Sans for supporting text. The logo is supplied as a transparent PNG with the original circle retained.

## Adding the booking system later
The `book.html` page is deliberately isolated so the future booking platform can replace the "coming soon" area without changing the rest of the site.
